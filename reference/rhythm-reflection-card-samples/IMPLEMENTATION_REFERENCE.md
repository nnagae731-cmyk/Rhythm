# Rhythm 月間振り返りカード 参考資料

このフォルダの画像は、完成イメージの参考です。
画像自体をアプリ内の本番素材として貼り付けず、構成・余白・配色・写真配置・装飾の方向性を再現してください。

## 仕様

- 無料版：写真最大2枚、基本テンプレート1種、基本カラー1色
- Premium版：写真最大5枚、テンプレート3種、カラーパレット4種
- 今月の言葉を自由入力
- 今月のベストを表示
- 共有時は1080×1920、9:16で画像化

## 写真枚数によるレイアウト

- 1枚：メイン写真1枚
- 2枚：2分割
- 3枚：大1枚＋小2枚
- 4枚：2×2
- 5枚：大1枚＋小4枚

## テンプレート

- Gallery：雑誌・ギャラリー風
- Film：フィルム・アルバム風
- Scrapbook：写真を重ねたスクラップブック風

## カラー

Premiumでは以下の4色を選択できるようにします。

- Lavender
- Blue
- Peach
- Green

テンプレート・色・写真枚数を組み合わせて表示し、色違いの完成画像を大量に保存する方式にはしません。

既存のRhythm Designにある花柄・チェック柄・ドット柄の雰囲気を活用してください。
