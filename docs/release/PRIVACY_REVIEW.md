# RhythmPace プライバシー公開前確認

2026年11月26日のLOCAL点検に基づく確認表。App Store Connectへの回答案を確定したものでも、法令適合や広告同意を保証するものでもない。アプリ・SDKの実際の通信、設定した配信地域、サービス管理画面を照合して回答する。

## コード上の根拠と残作業

| 対象 | LOCALで確認できたこと | 公開前に必要なこと |
| --- | --- | --- |
| TODO・Wish・日記・設定 | AsyncStorageと管理写真ファイルに保存。WidgetはApp Groupで共有 | Appleの「収集」の定義に沿い、端末外送信の有無をSDKも含め確認。端末内保存だけを理由にアプリ全体を「データ収集なし」にしない |
| 広告 | `react-native-google-mobile-ads`。バナーとリワードにNPA指定あり | SDKの識別子・利用データ・診断情報などをバージョンと設定に沿って確認。AdMob側のプライバシーメッセージ・配信地域・app-ads.txtを確認 |
| 広告同意 | 本番コードの検索ではUMPの同意取得・privacy optionsへの接続は未確認 | 対象地域の要件を確認し、必要なら広告要求前の同意状態判定・変更導線を別途実装／検証。NPA指定は同意管理完了の根拠ではない |
| ATT | トラッキング許可要求の実装は未確認 | 広告SDKと設定の実際の利用方法からATTの要否を決める。画面がないことだけで「トラッキングしない」と結論しない |
| 音声 | iOS音声認識・マイク権限を使用 | 音声認識の処理先・端末内限定の保証有無を確認し、ポリシー説明と一致させる |
| 写真 | ユーザー選択画像をアプリ・Widgetに使用。参照保護と不要写真cleanupあり | 写真選択の拒否・限定アクセス、削除後のWidget表示、バックアップ扱いを実機で確認 |
| カレンダー | ユーザー選択の取り込み導線と用途説明あり | 権限拒否でも他機能を利用できることを実機で確認 |
| 地図・共有 | 外部共有／地図アプリへの文字列受け渡し。公開ポリシーに共有予定での一時的な現在地利用への記述あり | 当該現在地利用の現行Native実装・OS用途説明を照合。実装を確認できるまで「現在地を使用する／しない」を断定しない |
| 購入 | StoreKitの3商品。価格・復元・状態取得を利用 | 購入データの開示区分、Apple側の処理との切り分けを確認 |
| Required Reason API | アプリ設定とWidgetにUserDefaults `1C8F.1` の記述 | 全SDKのPrivacy Manifestが完成Archiveに入ること、必要な署名・理由が揃うことを確認。1ファイルの存在だけで全体PASSにしない |
| 暗号化 | `ITSAppUsesNonExemptEncryption: false` | SDKを含めAppleの輸出コンプライアンス質問と適合するか所有者が確認。設定値だけで法的判定しない |
