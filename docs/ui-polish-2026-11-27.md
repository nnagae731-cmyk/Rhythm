# UIの空状態・可読性・見出し整理

基準：main `453af1e`（42 suites / 369件）。今の世界観・テーマ・写真の扱いを維持し、保存形式・モデル・集計・通知・購入/広告復帰フローは変更しない。commit/pushは行わず、同HEAD向けパッチで渡す。

## 空状態の条件と導線

| 場所 | ガイダンスの条件 | 既存表示へ戻る条件 | CTAの接続先 |
| --- | --- | --- | --- |
| 分析・記録の出発/準備実績 | 準備開始と出発の両件数が0 | どちらか1件以上 | 予定・出発タブ |
| 分析・時間と行動 | 選択期間にメトリクスのサンプル、行動率の母数、通知記録、曜日別サンプルが全て0 | いずれか1件以上 | 予定・出発タブ（集中タブにも従来どおり進める） |
| 分析・ルーティン | アクティブなルーティンに完了日がまだない | 完了日が1日以上 | ToDo・ルーティンタブ |
| 予定・出発 | 既存フィルタで対象になるカウントダウンが0件 | 1件以上 | 既存の予定追加フォーム |
| ToDo・ルーティン | 今日の対象が0件 | 今日の対象が1件以上 | 既存のタスク追加フォーム |

- 行動率リング/曜日グラフは実装上「時間と行動」にあるため、そこも対象とした。
- 分析・記録に渡す既存の日記/履歴は隠さない。記録前の登録済みルーティン名・解除操作・解除歴も維持する。
- 今日のルーティンが1件しかない場合も、指示どおり既存行を表示する。空白を埋める目的でダミー項目や追加カードは挿入しない。
- サンプル数値や見本を実データとして表示しない。集計式は変更しない。

## 全面写真の帯

- 実際に全面背景URIを表示している場合だけ、共通ヘッダー、ホーム日付の行、ホームタブの背面へ白系SVGグラデーションを配置。
- 写真本体・カード・日記カード・順序/余白の既存設定は変更しない。上部バナー画像は帯に含めない。
- 全面背景がない通常デザイン/トップ画バナーは帯を出さず、wrapperも加えない。
- 明るい石/暗い木目を想定したURIで本番Appの表示条件をテストしたが、写真の質感や実コントラストを描画検証したものではない。実機で明暗・石/木目/人物写真を確認する。

## その他の変更

- 比較画面中は外側の×を非表示にし、背面の案内をアクセシビリティ探索から外す。比較の閉じるボタンは右上1つ。背景タップとOSの戻るでも比較だけを閉じ、元の案内/購入stateを維持する。
- 比較列を76ptに広げ、列見出しは1行・必要に応じた縮小で維持。見出しの文言は変更なし。
- 予定タブはスケジュールに1.65倍の幅を配分し、全4ラベルを1行にする。最小縮小率0.75、選択ドットを維持。集中時間など他の文字の縮小仕様は変えない。
- TaskModalのタイトル枠はfocus時にテーマアクセント、非focus時にテーマ境界色を使う。枠の太さ・角丸・入力・保存処理は維持。
- 写真レイアウトの横スクロールは、計測した右端の続きがある時だけ24ptのフェードを表示し、末尾で消す。タッチを遮らない。
- 予定追加フォームの日付の□を、既存SVGライブラリによるカレンダー形状へ変更。日付選択処理は変更なし。
- 達成の瓶は既に実件数「○個のできた！」を瓶の近くに表示している。二重表示を増やさず維持し、回帰テストで確認。
- 任意項目のデザイン変更モーダル・フッターフェードは今回は加えない。
